# AI 管理与论文写作资料库

本仓库整理 AI 管理、企业数字化转型、数字消费者决策和人机协同主题的研究资料，以及论文写作、因果推断和期刊选择工具书。

> 仓库默认按私有研究资料管理。原始论文 PDF 体积较大且可能受版权限制，因此不纳入 Git；当前仓库只保留知识库、分析报告、提取文本、元数据、脚本和文献清单。

## 文件角色

| 文件角色 | 说明 |
| --- | --- |
| 原始文献 PDF | 各主题资料夹中的论文原文，方便检索和阅读 |
| 主题分类总表 | `论文主题分类总表.csv`，把 493 篇论文统一映射为 12 个主题，并保留各资料夹原始主题 |
| 选题导航 | `论文主题选题导航.md`，按主题汇总资料密度、代表文献、候选研究问题和可选方法 |
| 推荐与数据挖掘清单 | `推荐系统与数据挖掘_相关论文.md`，单独整理推荐、搜索、评价挖掘、因果决策与可信算法论文 |
| Word 知识库 | `100篇UTD24文献知识库完整版...docx`，将同主题论文整理成可连续阅读的知识库 |
| 分析/综述报告 | 对文献集合做分类、比较、综述和重点提炼 |
| 提取文本 TXT | 从 PDF 提取的全文或分页文本，便于全文检索和后续分析 |
| JSON 元数据 | 批处理结果和文献索引信息 |
| Python 脚本 | PDF 元数据提取、分页处理和文本整理脚本 |
| 文献清单 CSV | 记录当前本地文献路径、格式和大小，作为 PDF 未上传时的替代索引 |

## 选题入口

1. 打开 `论文主题选题导航.md`，先确定一个统一主题和候选研究问题。
2. 打开 `论文主题分类总表.csv`，按统一主题、来源资料夹或来源主题筛选论文。
3. 打开 `推荐系统与数据挖掘_相关论文.md`，查看推荐系统与数据挖掘方向的单独筛选结果。
4. 如需修改分类规则，编辑 `tools/build_topic_index.py` 或 `tools/build_recsys_reading_list.py` 后重新运行：

```powershell
python tools/build_topic_index.py
python tools/build_recsys_reading_list.py
```

## PDF 恢复方式

将原始 PDF 按上述目录名称放回本地资料夹即可。`文献清单.csv` 保存了文件清单，可用于核对缺失文件；因为 `.gitignore` 已排除 `*.pdf`，新增 PDF 不会误上传到仓库。
